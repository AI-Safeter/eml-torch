# Data and model attribution

Airfoil measurements are from Brooks, T., Pope, D., and Marcolini, M. (1989),
*Airfoil Self-Noise*, UCI Machine Learning Repository,
https://doi.org/10.24432/C5VW2C. The included data file is unchanged and is licensed
under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The arithmetic experiment uses [Qwen3-1.7B](https://huggingface.co/Qwen/Qwen3-1.7B),
revision `70d244cc86ccca08cf5af4e1e306ecf908b1ad5e`, by the Qwen team.
Its license is Apache 2.0; a copy is included as `llm/QWEN_LICENSE`.
Full model weights are not included. Component directions, feature projections,
and fitted predictors are experiment artifacts computed using that model.

Pendulum data are generated by the included numerical solver. PySR and other
dependencies retain their own licenses; their source distributions are not
vendored here. Application source code follows the repository's MIT license.
