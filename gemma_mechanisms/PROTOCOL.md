# Complete MLP replacement and arithmetic mediation

This prospective study starts from Gemma 4 E2B IT revision `3e22461f65e89153144f8adb70e3b8c2cc9845a7`. It is independent of the ongoing scalar study. No previous scalar, whole-block, KV, or J-space test results are used as fresh confirmation. `protocol.json` fixes the grid and acceptance criteria before collecting new model outputs. Data manifests and source hashes are frozen before training; selected checkpoint hashes are frozen before the gate and final evaluations. Final outcomes cannot tune the model. Amendments require a new version, an explanation, and fresh confirmation data.

## Replacement

The first target is the entire native MLP at zero-based layer 26, motivated by earlier localization. The surrounding attention, residual path, native normalizations, per-layer input contribution, and KV-sharing behavior remain native and are counted. Assign a student to `model.language_model.layers[26].mlp`; remove the original module from the deployed model. Neither a hook that edits its output nor an original-MLP residual is a replacement. Integration validation poisons the removed MLP's forward, verifies that none of its parameter objects remain registered, and exercises prefill and cached decoding. The deployed state contains no teacher tensor or teacher callback.

Each nonlinear student has a learned input encoder, D residual nonlinear stages, and a learned output decoder. D is 1, 2, or 4. Each stage normalizes its input, forms affine arguments, applies either centered EML `exp(left)-log(1+right²)-1` or SiLU, projects back to the bottleneck, and adds a scaled residual. EML uses two parallel argument projections in each nonlinear stage. SiLU uses a wider hidden layer to match total coefficients, including every bias, norm, decoder, and statistic, within 0.1%. The input/output bottleneck and sequential nonlinear depth are identical within each comparison. Trainable encoders avoid the previous fixed-projection restriction. Factorized linear students use the same budget ceilings and a single factorization; artificially stacking linear factors is unnecessary. Report their actual ranks, including any rank cap at the ambient dimension.

The two budgets are 3M and 6M stored coefficients; bottlenecks are 256 and 512. Each family gets three seeds, the same data, optimizer, stopping policy, and validation frequency. All attempted fits, nonfinite steps, gradient clipping, exponent clamps, losses, and training costs are reported. No post hoc seed exclusion. Affine input/output training statistics are counted and folded only after numerical equivalence is checked. Norm parameters inside the student remain counted.

Initialize the encoder/decoder from a training-only ridge map (penalty .001 on the normalized input covariance) into the leading output covariance eigenspace. Both nonlinear families start from the same map and output subspace, with small residual nonlinear stages. All projections subsequently train; the subspace is not fixed. The factorized linear baseline uses the same initialization at its actual rank. This removes a random decoder initialization as a confound. The output covariance residual is a lower bound only for the corresponding fixed diagnostic subspace, not a lower bound on every trained nonlinear network.

Teacher inputs and complete outputs supervise offline training on a balanced mixture of arithmetic and language tokens. Loss equally weights normalized raw output MSE and post-feedforward-normalization contribution MSE. Gemma normalizes the complete MLP output before adding it to the residual: a small raw MSE alone is insufficient. The native postnorm weights used by the training objective are not an extra deployed copy. They remain once in the original layer. Training and validation use CUDA; captured data may reside on CPU. No teacher inference occurs during offline fitting or deployment.

## Fresh data and evaluations

Arithmetic operands are unique across all splits, canonicalized for commutative operations, and exclude every clean/corrupt pair in the earlier frozen arithmetic study. In-distribution addition uses 500..999 by 500..999; multiplication 300..999 by 11..99; division 500..9999 by 51..99, including nonzero remainders and explicitly requesting integer quotient. Generated prompts use Gemma's native chat template with thinking disabled. Train on symbolic/prose formats and numeric continuations. Gate and final report both formats without conditioning on teacher correctness. New formats and longer operands/carry chains are separate diagnostic cohorts, never selection criteria.

FineWeb-Edu documents are selected from the pinned parquet shard, deduplicated by text hash and split by hostname to prevent same-site leakage. Use the first 256 tokens from each eligible document (at least 256 tokens). Record URL/domain, source row, text hash, token hash, and split; do not commit copied web text. This measures degradation on varied educational prose, not universal language competence or absence of pretraining contamination. ARC-Easy provides a separate general question-answering check: official validation for selection, disjoint hash halves of official test for gate/final. Use length-normalized conditional answer-text likelihood, no few-shot examples. It is a retention test, not a leaderboard replication.

Choose budget/depth per family using mean selection loss across seeds; then retain all three seeds of that configuration. Gate arithmetic and ARC loss upper bounds use a conservative paired regression bound (teacher correct/student wrong; improvements reported separately), with Bonferroni adjustment across four accuracy tasks and three seeds. Bootstrap language CE by document with the same familywise adjustment. Expansion requires every EML seed to satisfy <=1pp accuracy-loss upper bound, <=.02 nats/token CE increase upper bound, >=4x block coefficient reduction, and no nonfinite output. A bound failure can reflect limited sample size; distinguish that from measured degradation.

Only a passing one-block gate permits a newly frozen multi-block stage, starting with the listed neighboring layers. Reuse training data, but allocate fresh gate groups for each expansion; do not repeatedly select against the first gate. Reserve final data until the expansion decision and selected checkpoints are frozen. No expansion after a failed gate. Test the final selected configuration on the original final holdout even if the one-block gate fails, reporting it as a failed candidate, without tuning against it. Report all seeds and unconditional accuracy, teacher-correct subsets, carry classes, lengths, and formats separately.

The deployment targets are >=20% fewer **total stored model parameters**, >=10% lower end-to-end latency on the declared workload, and <=1pp loss on each accuracy task with uncertainty. E2B's large embeddings, unused multimodal parameters, all original buffers, student statistics, and live working memory are included in accounting. Offloading weights changes placement, not parameter count. A single block cannot achieve the total-model target. EML-specific benefit requires a paired confidence interval over matched SiLU at comparable storage and measured cost, not just proximity to the teacher.

## Causal arithmetic mechanism

Start with addition carry, not an assumption of a complete arithmetic algorithm. Quantities are hypotheses: operand unit/tens digits, carry into tens/hundreds, and corresponding result digits. Collect candidate states at the last prompt token and teacher-forced answer-prefix positions, across layers 8/14/20/26/32. Fit regularized linear probes on training groups, choose regularization/layer pairs on selection only, and include shuffled-label probes. Report held-out decoding before interpreting a feature. Predictions at answer-prefix positions are conditional analyses; final generated answer accuracy remains unconditional.

Use donor/recipient pairs with the same upper operand digits and controlled unit-digit changes that flip carry. Include same-carry donors with comparable numeric changes, matched-norm random subspaces, shuffled labels, and full-activation donors. Patch only the candidate subspace while preserving its orthogonal complement. Record changes to downstream candidate variables, the probability of the relevant output digit under a fixed answer prefix, and complete generated answers. Natural donor swaps and off-manifold feature edits are labeled separately. Include ablation, donor restoration, and blocking the proposed downstream mediator: a direction that steers an answer without mediating the donor effect is not a recovered mechanism.

Fit compact compositional EML equations from decoded upstream internal features to downstream features. Compare a linear equation, a carry-threshold symbolic rule, and matched-depth SiLU. Input features at inference come from the model, never ground-truth operands or target activations. Ground-truth variables are labels and an oracle diagnostic only. Evaluate predictions of original-model responses to withheld interventions, not just observational activations. Require >=50% counterfactual interchange accuracy, a positive lower confidence bound over matched random controls, and response NRMSE <=.2 on both ordinary and withheld formats/lengths. Apply multiplicity correction across candidate hypotheses; all failures remain visible.

Carry hypotheses must survive unseen operands, longer chains, additional digit lengths, and new formats. Addition evidence does not establish multiplication or division mechanisms. Only a validated causal mechanism may guide a subsequent replacement architecture, which must then preserve both ordinary answers and intervention responses on fresh data. If a mechanism is not validated, report the two experiments separately.

## Cost and failure analysis

Count unique parameter objects, persistent/nonpersistent buffers, CPU/GPU placement, checkpoint bytes, optimizer state, peak allocated/reserved GPU memory, training seconds, steps, and tokens. Benchmark the actual model with the original MLP absent. Synchronized warm-up and alternating paired baseline/student runs use the same dtype, attention implementation, inputs, fixed decode tokens, cache behavior, and compiler policy. Report prefill, cached decoding, throughput, peak memory, and end-to-end time separately. Compilation and loading are separate setup costs. Report GPU UUID, other process memory, and utilization; shared-device measurements cannot establish an exclusive serving result. Primary workload: batch 8, 512-token prefill, 32 decode steps. Also batch 1 and 128-token prefill. CPU embedding offload, if needed, must apply equally and be declared; never label it parameter compression.

Diagnose failures with train/selection learning curves, seed spread, gradient and exponent statistics, domain-specific and token-position-specific error, raw versus normalized contribution error, and low-rank output covariance residuals. Oracle projection of native outputs is a diagnostic lower bound for a fixed output subspace, never a deployable method. Compare bottleneck budgets to distinguish information/capacity limits from optimization; unseen-format degradation after in-distribution success is evidence of distribution shift. These diagnostics do not prove a mathematical limit on EML.

Sources: [Gemma model card](https://huggingface.co/google/gemma-4-E2B-it), [EML paper](https://arxiv.org/abs/2603.21852), [Arithmetic Without Algorithms](https://arxiv.org/abs/2410.21272), [FineWeb-Edu](https://huggingface.co/datasets/HuggingFaceFW/fineweb-edu), [ARC](https://huggingface.co/datasets/allenai/ai2_arc). The experiment tests this checkpoint and finite architectures; no universal claim is preregistered.
