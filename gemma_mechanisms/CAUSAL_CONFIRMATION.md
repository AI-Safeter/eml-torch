# Confirmation of arithmetic intervention routing

Selection tests rejected carry-probe directions as mediators. They also found
that replacing the last-token layer-26 residual with the donor residual does
not reproduce the donor response. Replacing that residual and the two shared
KV tensors reproduced every output logit exactly in 128 selection cases.
Earlier sliding-attention values, rather than keys or the current token's value,
carried most of the donor digit effect. These are prospective routing hypotheses,
not a recovered arithmetic algorithm.

Version 3 freezes these tests and the existing observational equations before
confirmation. Evaluate the first 256 eligible, previously generated donor pairs
in each of the gate and length/carry-shift cohorts, with both original formats
and both withheld formats. Report eligibility against all original groups;
never treat ineligible pairs as successful interventions. Preserve all native
donor errors. Report fixed-prefix agreement with the donor's true answer as a
diagnostic subset because a carry can change earlier digits. All primary
intervention rates use the full evaluated cohort, including inconsistent prefixes.

Primary routing prediction: transplanting both last-token residual and shared KV
reproduces donor logits bitwise. Contrast with residual only, KV only, each KV
type, keys/values, last/earlier values, same-carry donors, and matched-norm random
KV edits. Report exact counts and operand-clustered 95% uncertainty. A cache
content intervention does not identify a symbolic carry variable.

Retest the frozen operand-orthogonal carry direction at layer 26 against a
matched-norm random direction. After the donor-value intervention, restore the
layer-32 carry readout to the recipient value; compare a matched random block.
Use the original preregistered interchange and response-error thresholds for
mechanism claims. No passing routing result overrides failed carry mediation.

Evaluate all three training seeds of each observationally selected EML and SiLU
equation, with matched-depth controls, alongside the frozen linear, symbolic,
and identity maps. Inputs are decoded layer-26 quantities, not operand labels
or teacher targets. Predict layer-32 quantities and their changes relative to
the recipient. Report normalized response error and its denominator; do not
hide near-zero true responses. Direct edits at layer 32 are mediation tests,
not valid tests of an unmodified layer-26-to-32 equation. Cache-only edits keep
the equation's input fixed; their downstream effects directly test input
sufficiency. All equations and probes predate these confirmation outputs.

No full-model replacement gate operands are opened until the corrected BOS
replacement training grid and checkpoint selection are frozen. This prevents
mechanism results from influencing replacement selection on shared operands.
